Honest note: this scrambles variable names, hides every string behind runtime decoding, and breaks up numbers — it makes a script very unpleasant to read. No obfuscator (here or anywhere) can make a script truly unopenable, since whatever runs it has to read the real code eventually. Always keep your own unobfuscated copy, and skim the output once before sharing it.
About the key-system mode: it only runs in your browser — your template, secrets and script are never sent anywhere, even if your key-system has a real API key in it. The tool finds the loadstring(game:HttpGet(...))() line in your template and replaces it with your obfuscated script, embedded directly — so the final file has no second URL to protect.

Strings, encrypted

Every text string is converted to a byte table and decoded at runtime, so nothing readable sits in the file.

Names, scrambled

Local variables, function names, and parameters are renamed to short meaningless tokens.

Numbers, split
